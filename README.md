# Chat de producto con Firebase Realtime + NestJS

Monorepo con tres piezas:

- `api/` — API NestJS (pedidos por REST)
- `app-cliente/` — Cliente móvil React Native CLI
- `app-comercio/` — Comercio web React (Vite)

> Requiere Node 22 (`nvm use` en la raíz toma la versión de `.nvmrc`).
